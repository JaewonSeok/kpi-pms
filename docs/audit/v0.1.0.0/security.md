| 8-2 | 시크릿 관리 — 저장 위치 통제 | **부적합 → 조치 완료** | ★★ 운영 Supabase 접속 문자열이 `~/.claude/settings.json` 의 `permissions.allow` 에 **평문 13회** 누적. 호스트·사용자·DB명 포함. 전 직원 평가 데이터 접근 가능 상태. **비밀번호 로테이션 + 평문 제거 완료** |

| 8-6 | Vercel·GitHub 팀 계정 MFA | **확인 불가** | 조직 계정 설정. 저장소 조사로 판정 불가 |

### ★ 8-2 의 의미

이 항목이 이번 검사의 최대 발견이다. **저장소 밖에 있어 어떤 시크릿 스캔도
닿지 않았다.** #287 로 도입한 gitleaks 의 검출 범위 밖이며, 1회차 자가 진단이
`.gitignore` 에 `.env*` 가 있다는 근거로 "부분준수" 판정한 항목의 실제
노출면이었다.

**구조적 원인**: 명령에 비밀번호를 인라인으로 넣고 AI 도구에서 승인하면
`permissions.allow` 목록에 명령 전문이 영구 누적된다. 평문을 지웠으나
**같은 경로로 재발할 수 있다. 미조치.**
