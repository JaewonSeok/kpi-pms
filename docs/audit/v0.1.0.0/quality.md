## 3. 참고 — 자체 측정치 (감사 아님)

감사 결과가 아니라 kpi-pms 가 자체적으로 확인한 수치다. 품질경영본부의
판정을 대체하지 않는다.

### 3.1 테스트 자산

| 지표 | 값 | 측정일 |
|---|---|---|
| `tests/` 하위 테스트 파일 | 168 | 2026-09-17 |
| CI 체인이 실행하는 파일 | 144 | 2026-09-18 |
| 부채 목록 (체인 미등록, FAIL) | 23 | 2026-09-17 |

★ 2026-09-17 이전에는 **81개만 실행**되고 있었다. 87개가 체인 미등록
상태였으며 감시 장치가 없었다. #305 로 64개 등록 + 검출 자동화.

★★ **표준 §4 는 "수치 충족만을 위한 무의미한 테스트를 막기 위해 AI 리뷰로
테스트가 실질 검증을 하는지 함께 확인" 을 요구한다.** kpi-pms 에는 이 확인이
없다. 실측에서 `org-kpi-team-ai-workspace.test.ts` 가 소스 텍스트 존재만
검사하고 함수를 호출하지 않음이 확인됐다 — 감사 귀속 코드를 통째로 제거해도
7/7 PASS 했다. **이런 테스트의 비중은 미측정이며, 이 항목이 3.1 판정의
실질을 좌우한다.**
