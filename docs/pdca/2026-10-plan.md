## 2. 우선순위 A — 보안 (반드시)

### A-1. 관리자 인증 경로 정비
- `src/lib/auth.ts` 의 `ADMIN_PASSWORD` 평문 비교를 break-glass 격리로 전환
  - 기본 비활성 (`ADMIN_BREAKGLASS_ENABLED`)
  - bcrypt 해시 (bcryptjs 는 이미 설치돼 있으나 미사용 상태)
  - 시도 전건을 `audit_logs` 에 기록 (실패 포함)
- ★ GWS 장애 시 유일한 진입로다. 잠기지 않도록 롤백 경로를 먼저 확보한다
- 해소: 1회차 시큐어코딩 #26/#31

### A-2. 로그인 실패 잠금 + MFA 위임 증적
- 실패 횟수 제한 구현
- MFA 는 GWS 도메인 2단계 인증으로 위임하되, **적용 상태 증적을 확보**해
  `docs/security/` 에 보관
- ★ 증적 없는 위임은 다음 진단에서 다시 잡힌다
- 해소: 보안기능 체크리스트 #2, #4 (등급 상)

### A-3. 로컬/운영 DB 접속 분리
- `.env` 를 로컬 DB 로 되돌리고, 운영 접속은 별도 파일로 분리
- ★ 현재 `migrate reset` 한 번이면 운영 DB 가 비워진다
- 해소: 2회차 3-10

## 5. 명시적 비목표

이번 달에 **하지 않는다**. 하려다 못 한 것과 구분하기 위해 미리 적는다.

- 버전 4자리 전환 / Git 태그 / CI 빌드번호 — A·B 보다 위험도가 낮다
- SBOM — 권고 사항
- `@ts-nocheck` 제거 — 잠복 타입 오류 규모 미상, 별도 사이클 필요
- 대행 귀속 과거 데이터 추정 리포트 — 신규 기록은 정상화됐고 과거분은 급하지 않다
- `C:\dev` 클론 제거 — ★ 표준 문서 저장소(`rnd-ai-sdlc-main`)의 유일한 사본이
  거기 있다. 옮긴 뒤에야 지울 수 있다
- 서버군 4단계 매핑 / Docker 수동 배포 폐기
